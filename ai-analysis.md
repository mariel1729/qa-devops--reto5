# Análisis asistido con IA

## Objetivo
Usar IA para resumir hallazgos, preparar reportes y mejorar la documentación del portafolio QA.

## Ejemplo de uso
1. Subir los reportes de prueba, Lighthouse o accesibilidad a una herramienta de IA.
2. Pedir un resumen ejecutivo con hallazgos, impacto y recomendaciones.
3. Convertir el resultado en una nota breve para el README o un informe de QA.

## Prompt sugerido
> Resume los resultados de pruebas de calidad de QA Store en formato ejecutivo: hallazgos, impacto, prioridad y recomendaciones.

## Valor esperado
La IA acelera la documentación, reduce el tiempo de análisis y mejora la presentación del portafolio.
